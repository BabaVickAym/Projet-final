# Guide d'Installation

Suivez ces étapes pour configurer l'environnement de développement sur votre machine locale.

### Prérequis

-   [Node.js](https://nodejs.org/ ) et npm (si projet TypeScript) / [Python 3](https://www.python.org/ ) et pip (si projet Python)
-   [Git](https://git-scm.com/ )

### 1. Cloner le dépôt

Clonez le dépôt sur votre machine et placez-vous sur la branche `develop` :

```bash
git clone [URL_DU_DEPOT_GITHUB]
cd [NOM_DU_DEPOT]
git switch develop
