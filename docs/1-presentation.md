# Présentation du ProjetAPI

**ProjetAPI** est une API REST simple conçue pour la gestion des soumissions de projets étudiants dans le cadre d'un cours.

Elle permet de soumettre des projets, de les lister, de les noter et de les filtrer, offrant ainsi une base pour simuler un flux de travail collaboratif en développement logiciel.

### Objectifs Pédagogiques

-   Simuler un environnement de développement collaboratif avec Git et GitHub.
-   Apprendre à gérer les conflits, notamment sur des ressources partagées comme le fichier de données `db.json`.
-   Mettre en pratique les revues de code (Pull Requests) et l'intégration continue (GitHub Actions).

### Technologie

Ce projet est développé en Python et utilise un fichier `db.json` pour le stockage des données afin de maximiser les opportunités d'apprentissage liées à la gestion des conflits.
